# Gridiron Manager

Division III football management, 1880–2026 — in a single HTML file.

## How to play
1. Download `gridiron-manager.html` from this repository.
2. Double-click it — it runs offline in any modern browser. No install, no server.
3. From the **Era Engine** page, pick any era (1880–2026) and **Begin a season**: the entire game then follows that era's rules — scoring values, downs, playbooks, position names, recruiting, news language, and postseason format.
4. Click **Play game** to call plays drive by drive. Progress auto-saves in your browser.

## Features
- Playable play-calling engine with era-accurate rules (1883 goal-kick scoring, 1892 flying wedge, 1906 turnover-on-incomplete forward pass, 1912 modern field, 1958 two-point conversion, modern RPOs)
- Ten documented era profiles with a period language gate that blocks anachronisms
- Roster, recruiting, schedule, program legacy, news generation — all era-gated
- Dark mode, search, alerts, mobile-responsive, auto-save
