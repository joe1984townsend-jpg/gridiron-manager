# Gridiron Manager

Division III football management, 1880–2026 — in single HTML files. No install, no server, no build step.

## Two versions

| File | What it is |
|---|---|
| `d3-gridiron-manager.html` | **Full game (v6.0.0).** Create a coach, choose from 244 real D3 programs, and run a career in a living league — 1880 to 2026. |
| `gridiron-manager.html` | **Compact companion.** A smaller era-engine showcase: pick one of 10 documented eras and play a season drive by drive. |

## How to play

1. Download a file from this repository (green **Code** button → **Download ZIP**, or open the file and use **Raw** → save).
2. Double-click it — it runs offline in any modern browser.
3. Progress auto-saves in your browser.

## Full game (v6.0.0)

- **Coach creation** — name, hometown state, background, attribute points, offensive and defensive schemes (era-gated: Spread 1970, Air Raid 1985, 4-2-5 1992…), difficulty, and a history mode (guided vs. alternate history).
- **Choose any school** — 244 real D3 programs with mascots, conferences, prestige ratings, colors, stadiums, and locations; filter by conference or by programs near your hometown.
- **Careers from 1880** — pre-1920 two-way elevens, goals-and-touchdowns scoring before 1883, graduate-manager mode before paid coaches, era-accurate conference maps and program availability.
- **Living league** — full standings, polls, playoff formats (four-team Stagg Bowl era through the 40-team model), coach carousel with hiring and firing, recruiting with the transfer portal, facilities, finances, rivalries, injuries, film study, awards, and a Hall of Fame.
- **Era Lab tab** — a read-only accuracy lab showing the exact rules, postseason format, travel model, and tactics available in any season 1869–2026, driven by the same functions the simulation uses.
- Save slots with automatic weekly backups, save migrations, commissioner mode, and an in-game guide.

## Compact companion

- Ten documented era profiles (1880, 1883, 1892, 1906, 1912, 1934, 1958, 1973, 1999, 2026) with a period language gate that blocks anachronisms.
- Playable play-calling engine with era-accurate rules: 1883 goal-kick scoring, 1906 turnover-on-incomplete forward pass, 1912 modern field, 1958 two-point conversion, modern RPOs.
- Roster, recruiting, schedule, program legacy, and news generation — all era-gated.
- Dark mode, keyboard shortcuts, mobile-responsive, auto-save.
